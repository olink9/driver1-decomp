  Look for families (same shape, different constant) and do them in one go.

## Lessons from fr-001..004 (160/160 matched)
- `lui/li/sb|sh|sw %lo(D)` = `extern char|short|int D; D = N;`. Two-offset stores off one base = `extern char D[]; D[0x14]=n; D[0x24]=n;` in asm order.
- A store via a SEPARATE `addiu +0x10` then `sb 0xC(v0)` = a pointer local: `T *p = D; p += 1; p->r = 255;` (index forms fold the offset, ~80%).
- `jal X; v0 = 0` in the slot = `int f(void){ g(); return 0; }`. A trailing `addiu v0,-1` in the jr slot is `return -1` only if v0 is not just the last stored value.
- Generating C from fnasm output with a small script works well for families of identical shapes.
- (fr-005/6) Table flag setters `D_tbl[D_idx].f = 1` = 16-byte struct, `char f` at +4; `if (i != -1) D_tbl[i].f = 0;` with `int i = D_idx;`. Toggles: `D_x ^= 1;` with `int D_x`. C89: declarations only at block start.
- (fr-010..012) `f2(D,0,0)` with `extern char D[]` (array extern = lui/addiu address). Keep a call result across a later call: `int r = g(); f2(...); return r;`. Address-constant tables: `extern int D[]; D[2] = (int)sym;`.
- (fr-013..015) Two pointers over one struct array: `E *q = p; while (q->f) { ...; q++; }` with the real element size (add trailing fields). A store in the first jal's delay slot = the global assigned before the first call. `D += 100; if (D > 0) D = 0;` gives blez. Unused locals that only size the frame count as FAKEMATCH - tag them.
- (ov1-opus) Return constant loaded BEFORE a final store of another constant (`li v0,R; li v1,1; sw v1`) = the last callee returns int: declare it `int`, not void (a 2nd set of v0 kills the birthing boost). Address computed too early after `p += n`: put it in a new single-set local (`q = p + n;`) where it should appear.
- (fr-016..018) 192-212 B menu loops share one skeleton: `D=0; func_001C2644(tbl,n,0); func_001C2114(0,tbl2,1); for(;;){ func_000514E0(); r = func_001C26E4(tbl,&D); if (r) break; func_001C19C4(); func_001C1BD4(tbl2); func_001C11E4(); }` + a varying tail. 8-arg calls: count stack stores at 0x10-0x1C(sp). GTE: macros from clippedPoly.c (+stsxy3c/nclip/stopz/stsz3c). distrobox eats stdin in `while read` loops - use `</dev/null`.
- (coord) fnscore 100 does NOT check jump-table CONTENTS when the case bodies have the same shape: func_001C9298 scored 100 with the wrong case->value mapping (wrong behaviour!). Read the jtbl .word order against the bodies' loads/constants for every switch; linkcheck (byte compare of .rodata) is what catches it.
- (fr-019..021) `volatile int` FrameCnt (D_00097534) fixes ++/=0 placement. Per-arm shared tails must be written in each arm. Struct copies of 3 ints: field-wise (.x/.y/.z) for lw,lw,lw/sw,sw,sw. A leaf with a frame but no saves = a local aggregate reserving space (pads that only size the frame are FAKEMATCH). From 300 B up, workers are Opus (Sonnet yield fell to ~60% at 212-296 B).
- (fr-022..024) D_000C6FEC = D_000C6F04 + 0xE8 (a field; func_001C4BC8 mirrors main func_0006C964). `sb sN` with no andi before a later arg = an int param. Two stores to one global survive only with another store between them. A pointer rematerialised (fresh lui) after a join = the same local assigned again (`p = D_tbl;` twice). Port siblings verbatim (func_001C19C4 = func_001C18AC twin).
- (ov1-opus 2) Mask code `(*a & 0xFF000000) | (b & 0xFFFFFF)` = PsyQ addPrim/setaddr on a `P_TAG {unsigned addr:24; unsigned len:8;}` bitfield. A switch tree that falls through into the default: write `case 0: default:` FIRST (source order = code order).
- (mc-001/2) MCARD: D_000EE930 = array of 0x404-byte records (`{short s; char c2,c3; void *p4; 15 x 0x44 entries}`), index `D[n].f` directly (a local `h = &D[n]` changes lui order). Card poll skeleton: `n=999; do { VSync(0); if (func_00078E4C(0,&r[0],&r[1])) break; } while (--n != -1);`. A 3-way switch = compare chain, case order in source = block order. DB double-buffer: `extern DB D_000BDFA4[]` (0x80-byte DB), `current = D; D_00097524 = D + 1;`.
- (mc-003..005) MCARD layouts: D_000EE930 entries 0x44 B from record +8 (`u8 idx @0x40, n @0x41`), record +0 `unsigned short` flags; D_000EFC08 = 32 texture sheets x 0x174 (`{int used; u8 slot; pad; short tpage; int count; ENT e[10]}`, ENT 0x24 = `{char name[16]; short clut; pad; int x,y,w,h}`); D_000EF150/EF600 = POLY_FT4[2][15]/POLY_F4[2][15]. Prim builders: port func_000E7398 / func_000EB5B8. getTPage into a short field: via a `short tp` local. Input handlers: write each mode's arm in full, cross-jumping makes the shared tails.
- (fr-025..027) Chained zero store `A.x = B.vx = 0;` fixed a swap of two hoisted addresses. Switch cases sharing a tail by fall-through: write cases in TARGET CODE ORDER. Hoisted invariant losing an s-reg: duplicate the shared tail into both arms (real C). One `return r;` set in if/else keeps the return value in an s-reg; separate `return 0/1` fold away. Model DB/DRAWENV/DISPENV as real structs. OPEN: target computes `0x2C & 0xFC` at runtime (func_001C4810/5D28) - every C form cse-folds it.
- (fr-028..031) Cross-jumped shared tails land in the LATER arm only with one `return` at the end (no early returns). A constant re-lui'd at each use in a loop appears ONCE in source (loop.c hoists only if threshold*savings*life >= insns; check -dL). A constant address in an s-reg set after other invariants = a pointer assigned INSIDE the loop body. Near-tie s-reg swap: `k++` in each arm. Stack locals in declaration order, 8-byte slots; a gap = a missing small local.
- (mc-006/7) addPrim on a GLOBAL prim: write the OT store as `current->ot[k].addr = (unsigned)&G;` (not via the local prim pointer) so loop.c hoists the right lui. Exit blocks before the loop = `if (c) { f(); break; }` with the call inside. An unused 8-byte gap next to a poll array = an inlined sibling with a dead branch (static inline copy). MCARD font table D_000ED8B0 = 0x414-byte entries; text state at D_000ED530.. (see mcard/func_000EB1F8.c, func_000EAE3C.c). cc1 dumps for overlays: pilot/scripts/dump0.sh (-G0).
- (fr-032..035) Prim xy word stores swapped by sched1: `*(long *)&p->x0 = ...` on the real POLY_FT3 (non-MEM_IN_STRUCT). Adjacent prim arrays = separate externs, not a 2-D array. Product operand order follows C order. Two prim blocks in one function: a separate block-local pointer pair per block. A pointer global stored after a call with its lui too early: `REC *r = f(); D = r;`. A literal load address (0xD0200) gives a reloc-only diff against splat's label - fine.
- (mc-008/9) Blocks rounded up: `size / 8192 + (size % 8192 != 0)`. Refs are weighted by loop depth: copying a fail tail into the loop body (instead of `goto fail`) adds refs and fixes s-reg swaps (real C; cross-jumping re-merges). A value loaded before a poll loop = an inlined sibling (func_000E7F5C); the helper's parameter order sets where copies are born.
- (fr-036/7) `sw x, D; lhu D` with the load kept below the struct stores = a struct-cast read `((HALF *)&D.vx)->lo` (MEM_IN_STRUCT). Separate locals per normalised vector and per SquareRoot0 result. A volatile pad word read once for two tests = read into a local there. func_001C753C is CALLED with (0, 50) - its matched void(void) definition (FAKEMATCH pad[8]) may really take two unused params; revisit.
